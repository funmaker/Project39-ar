# OpenViva character data

Animations, animation manifest, animator controller and voice of the character ("Shinobu"/Lily) from
[OpenViva](https://github.com/OpenViva/OpenViva), MIT License, Copyright (c) 2021 OpenViva Community.

Generated by `tools/openviva/import.py` from the OpenViva Unity project:

- `anims/*.p39a`: animation clips baked into a skeleton independent humanoid space (see `src/component/miku/anim`).
- `controller.json`: the `LilyAC` animator controller (layers, states, blend trees).
- `animations.json`: the animation manifest (`Lily.AnimationManifest.cs`) and body states.
- `skeleton.json`: rest pose of the source rig, used for retargeting.
- `voice.json`, `voice/`, `sfx/`: voice lines and sound effects, converted to ogg vorbis.
